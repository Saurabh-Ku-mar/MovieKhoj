# MovieKhoj
1. `npm install` 2. copy `.env.example` to `.env.local` and fill in 3. run `supabase/schema.sql` in Supabase SQL editor 4. `npm run dev`
Add movies via Supabase Table Editor (set published=true) and add rows to external_links (approved=true, active=true, https URL on a domain listed in APPROVED_DOMAINS).
